# Archived shot builds

Earlier builds of shots that later passes replaced, copied out of `snapshots/` (which is scratch and git-ignored).
Several are the **traced** builds (vector traces of source frames, redrawn by code) that measured closer to the source
than the hand-drawn builds that replaced them — e.g. `s28-prev/s28.traced.js` (σ12 ≈ 2.5), `s27d-prev/` (ΔE 3.2),
`f2r-prev/` (the traced colour site, ΔE 3.2). Each folder's `.md` explains what it is and which helpers it needs.
