Measurement scripts for s02 (not loaded by the film). They read SOURCE frames and write shapes/values/tracks only —
no pixels. Every data module in `src/shots/s02/*.js` that holds shapes was generated by one of them.

Common pieces
- `invgrade.py` — inverse of the film's global grade (src/lib/post.js: flicker, vignette, S-curve, halation), so
  measured values are pre-grade paint values the shot can draw directly.
- `levels.py` — vectorizes nested level masks into shapes with holes (even-odd), each with the mean paint value of its
  own band; optional square tiles (overlapping 4 px) keep values local.
- `wing_local.py` — warps a flight frame into the owl's own frame (owl units, root at the origin, bank removed) using
  ROOT in s02.js.

Scripts → data
- `trace_designer.py` → averaged frames: A (face, 8.24–8.64 s), E0 (stare eyes, 6.08–6.88), E1 (look eyes, 8.96–10.44),
  grade inverted (.npy, scratch). Its stroke tracer is no longer used by the film.
- `trace_poster.py` + `tojs_poster.py` → `faceInk.js`: pale / grey / ink levels relative to the local paper (r < 0.9,
  0.75, 0.45 of a dilated envelope), 2x, tiled 96 px (2x). Irises of the stare separate (moved per frame).
- `trace_room.py` + `tojs_room.py` → `roomInk.js`: the shelves round his head (8.24–8.64 s) and the carton stack at
  the hold (14.48–15.92 s), 13 brightness levels. What the sitting owl hides is taken from 16.16–16.52 s with the
  flying owl masked (env WINGS, FLYREG); the rest inpainted.
- `trace_owl.py` + `tojs_owl.py` → `owlInk.js`: the sitting owl (open / heavy-lid / shut eyes) and the flying owl's
  body without wings (median of the aligned frames 17.84–19.12 s), 10 levels.
- `fit_root.py` (PART=head) → ROOT in s02.js: per-frame similarity of the flying owl's head against that median.
- `measure_wings.py` + `tojs_wings.py` → `wings.js`: both wing silhouettes on every frame 15.88–19.12 s in owl
  units (segmented on the warped frame, body removed, grown under the body), and their interiors as 4 levels.
  Left-wing frames 414–419, 421, 422 (merged with lit cartons) = the right wing mirrored; right 437 = a morph.
- `trace_pan.py` + `tojs_pan.py` → `panInk.js` (all pan frames 10.56–14.40 and 16.56–19.12 in world coords, weights
  favouring less blurred frames, owl masked by its measured silhouette; 17 levels, tiled; values per pan) and, with
  FRAMES=452..478 COVLEV=1 TILE=100000 BOX=-240,-1000,2400,1000, `retInk.js` (the softer face of the return pan).

Typical run (scratch paths): geo.json is exported from designer.js / hairShapes.js (HOODIE, SKIN, BEANIE, LAPTOP,
EYES, DROPS, HAIR).
